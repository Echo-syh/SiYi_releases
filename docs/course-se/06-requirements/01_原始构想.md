# 软件原始构想

> 说明：思懿目前已经开发到 v0.x。下面这份构想是按开发前的原始意图还原的起点（2026-10-20 整理），作为本次需求获取作业的输入，不是当时留下的原始文档。

## 一句话

做一个 Windows 桌面软件，把「读论文、管文献、译文献、问 AI」放进同一个窗口。

## 起因

我读论文时的实际流程是：PDF 阅读器开着论文，Zotero 开着文库，浏览器开着翻译，聊天窗口开着大模型。看到不懂的段落，复制到聊天框里问；问完再切回 PDF；过几天想找当时问过的那句话，得翻聊天记录。四个工具各管一段，中间全靠手工搬运。

## 我希望它做到的事

1. 能直接打开 PDF 论文，读的时候旁边就能问 AI。
2. 问 AI 的时候，它应该真的读过这篇论文，而不是只看到一个文件名。
3. 论文要能存起来、分类、打标签、记笔记，像 Zotero 那样。
4. 英文论文能译成中文，最好能原文和译文对照着看。
5. 我的论文、笔记、对话都放在自己电脑上，不要传到别人的服务器；API key 也要安全。

## 我还不确定的

- 「真的读过论文」到底是读多少？整篇还是我指定的几页？
- 数据都在本机，但问 AI 总要把内容发出去，这条线怎么划？
- 翻译是自己做，还是调用别的工具？
- 除了读论文，读的过程中产生的想法记在哪儿？
