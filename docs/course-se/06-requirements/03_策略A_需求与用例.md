# 策略 A 输出 · 初步软件需求与用例

> 由第 1–3 轮访谈整理。编号 `FR-A-xx` / `NFR-A-xx` / `UC-A-xx`，括号内为访谈来源，便于溯源。

## 1. 软件目标与范围

**目标**：把读论文、管文献、译文献、问 AI 收进一个本地优先的 Windows 桌面窗口，消除工具间的手工搬运，并让 AI 的回答建立在论文正文之上。

**范围内**：PDF 阅读、文库管理、就论文提问、笔记、日记、全局搜索、论文翻译（调用本机外部服务）、服务商配置。

**范围外**：文献下载/爬取、在线协作与分享、翻译排版重建、移动端、云同步。

## 2. 利益相关方

| 利益相关方 | 关注点 |
| --- | --- |
| 读者（研究者本人） | 读得顺、问得准、找得回 |
| 同组同学 | 能上手、数据可迁移 |
| 导师 | 只读笔记，不装软件 |
| LLM 服务商（外部系统） | 接收请求、返回流式结果 |
| 本机翻译服务（外部系统） | 接收 PDF、返回译文 |
| 开发者 | 单人一学期可完成、依赖合规 |

## 5. 用例

### UC-A-01 导入论文

- **参与者**：读者
- **描述**：读者把 PDF 拖入窗口或选择文件，系统建立条目与附件，并尝试补全元数据。
- **前置条件**：软件已启动；PDF 在本机且可读。
- **后置条件**：条目与附件入库；元数据已补全或标记待补；重复文件不产生新条目。
- **基本交互**：拖入文件 → 识别/去重 → 建条目 → 抽取首页 DOI → CrossRef 补全 → 展示结果。

### UC-A-02 从 Zotero 导入

- **参与者**：读者（文献管理者）
- **描述**：把 Zotero 中已有的分类、条目、附件迁移进来。
- **前置条件**：本机存在 Zotero 数据或导出文件。
- **后置条件**：能对上号的条目/分类/附件导入；对不上号的不导入并报告。

### UC-A-03 组织文库

- **参与者**：读者
- **描述**：建立分类树、把条目放入多个分类、打标签、写笔记。
- **前置条件**：文库中有条目。
- **后置条件**：分类/标签/笔记持久化，并可被检索。

### UC-A-04 阅读 PDF

- **参与者**：读者
- **描述**：打开条目附件，翻页、缩放、跳页阅读。
- **前置条件**：条目有可用附件。
- **后置条件**：页面正确渲染；附件丢失时给出可理解提示。

### UC-A-05 就论文提问

- **参与者**：读者、LLM 服务商（外部系统）
- **描述**：读者在阅读界面提问，模型按需读取当前论文的页/检索全文，回答带页码依据。
- **前置条件**：已打开论文；已配置可用服务商与密钥；论文有可提取文本。
- **后置条件**：回答与论文/对话绑定；引用页码可核对；无文本层时明确告知。

### UC-A-06 选中文本提问

- **参与者**：读者、LLM 服务商
- **描述**：选中 PDF 中的一段文字，就这段文字提问。
- **前置条件**：PDF 有文本层；已选中文本。
- **后置条件**：回答针对选中片段；片段与回答可追溯。

### UC-A-07 记录笔记

- **参与者**：读者
- **描述**：在条目下记录阅读笔记，并可导出。
- **前置条件**：已打开条目。
- **后置条件**：笔记保存并绑定条目；可导出 Markdown。

### UC-A-08 写日记

- **参与者**：读者
- **描述**：记录不绑定论文的想法、实验记录、组会纪要。
- **前置条件**：软件已启动。
- **后置条件**：日记保存，并可被全局搜索命中。

### UC-A-09 全局搜索

- **参与者**：读者
- **描述**：Ctrl+K 唤起搜索，覆盖对话、文库、日记，回车直达。
- **前置条件**：已有对话/文库/日记数据。
- **后置条件**：命中项高亮；回车打开对应对象。

### UC-A-10 翻译论文

- **参与者**：读者、本机翻译服务（外部系统）
- **描述**：调用本机 zotero-pdf2zh 翻译当前论文，译文本地留存，可双语对照。
- **前置条件**：已打开论文；翻译服务可用；已配置翻译后端。
- **后置条件**：译文副本存本地；可原文/双语切换；服务不可用时给出安装/启动指引。

### UC-A-11 配置服务商与密钥

- **参与者**：读者（管理员）
- **描述**：填写 OpenAI 兼容端点、密钥，选择厂商与模型。
- **前置条件**：持有服务商 endpoint 与 key。
- **后置条件**：配置保存；密钥加密；界面仅显示末四位；可测试连通性。

### UC-A-12 中断后继续生成

- **参与者**：读者
- **描述**：上一次生成被强杀/断电中断，重启后恢复半截内容并继续。
- **前置条件**：应用曾在中途退出；数据库中有半截消息。
- **后置条件**：半截回答仍在；可继续生成；清扫逻辑不误删内容。

### UC-A-13 删除条目/附件

- **参与者**：读者
- **描述**：删除条目或附件，选择是否连文件一起删。
- **前置条件**：条目存在。
- **后置条件**：按选择删除；有确认；译文副本随附件清理；数据删除彻底。

## 6. 本版特征（供对比用）

- **优点**：来源可逐条追溯到问答；异常边界较全（重复导入、附件丢失、扫描件、强杀恢复）；对本地优先与安全边界有明确表述。
- **已知缺陷**：
  1. 部分需求把**技术方案写进了需求**（Electron、SQLite、Ctrl+K、`%APPDATA%`），属于过度约束；
  2. 存在**复合需求**（FR-A-05 同时包含读页、检索、引用），不利于验收；
  3. 仍有**缺失场景**：整库备份/恢复、代理设置、模型上下文超限、超长对话、PDF 标注/高亮、引用导出、自动更新、可访问性、国际化；
  4. 「中文两个字就能搜到」等表述**不可度量**；
  5. 访谈由同一模型分饰两角，存在**自我确认偏差**，未产生真正的分歧。
