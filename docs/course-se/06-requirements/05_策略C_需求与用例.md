# 策略 C 输出 · 修订后的初步需求与用例

> 策略 C 的原始产出（分析师 Agent）见 `04_策略C_多Agent记录.md`：25 条 FR、15 条 NFR、9 个用例。
> 评审者 Agent 的结论是「不能进入下一阶段，只能进入修订后复审」。本文是**按评审意见修订后的 C 版**，也是与策略 A 对比时使用的 C 版。

## 2. 功能性需求（修订版）

> 优先级：高/中/低。`[假设]` 表示原始构想未明示、为完整性补充的条目。

### 阅读

| ID | 需求 | 优先级 |
| --- | --- | --- |
| FR-01 | 打开本地 PDF，支持翻页、跳页、缩放、连续滚动；大文件不得卡死界面。 | 高 |
| FR-02 | 显示 PDF 目录并可点击跳转。`[假设]` | 中 |
| FR-03 | 阅读与问答可在同一窗口协作完成；不规定并排/切换/分隔条等具体布局。 | 高 |
| FR-04 | 选中文本后就地提供「问 AI」「翻译」入口。 | 高 |
| FR-05 | 重开同一论文时恢复上次阅读位置。`[假设]` | 中 |

### 文库

| ID | 需求 | 优先级 |
| --- | --- | --- |
| FR-06 | 导入 PDF 时建立条目与附件；附件可复制入库或引用原文件，由用户选择；元数据优先从首页 DOI 经 CrossRef 补全，失败或低置信时保留空值/原值，不得写入错误值；可手填，不阻塞入库。 | 高 |
| FR-07 | 支持多级分类、多标签、条目多分类归属；批量修改列为 v1.1。 | 高 |
| FR-08 | 每篇论文可写笔记并关联该论文；笔记支持 Markdown 编辑与预览。 | 高 |
| FR-09 | 删除分「移出文库（软删除）/彻底删除」；软删除可恢复；彻底删除须清理数据库记录、磁盘附件、译文副本；v1 不产生、不迁移、不管理 PDF 批注。 | 高 |

### 问答

| ID | 需求 | 优先级 |
| --- | --- | --- |
| FR-10 | 提问以实际读取的论文内容为依据；回答依据的页/片段必须可查看；不得只给文件名或摘要就冒充全文。 | 高 |
| FR-11 | 回答标注依据的页码或章节；引用只能来自抽取层页-段映射或工具返回结果，模型自报页码不得直接作为可跳转引用；无法定位时明示；回答状态分全文覆盖/部分覆盖/未找到三态。 | 高 |
| FR-12 | 问答自动保存，并与论文及提问位置关联。 | 高 |
| FR-13 | 可对选中段落直接提问，片段、问题、回答三者可追溯。 | 高 |
| FR-14 | 同一会话支持多轮追问并保留上下文。 | 中 |
| FR-15 | 超出上下文/步数上限时，必须标注已读页码范围；部分覆盖时禁止输出「论文没有提到」；不得静默截断。 | 高 |

### 翻译

| ID | 需求 | 优先级 |
| --- | --- | --- |
| FR-16 | 将当前页或选中段落英译中；译文标明由外部服务生成。 | 高 |
| FR-17 | 提供原文/译文对照；对齐粒度以翻译服务实际输出为准；对否定、数值、专名三类抽样验收；用户可标记问题。 | 高 |
| FR-18 | 译文副本随论文保存；重复查看不重复翻译、不重复计费。 | 中 |

### 搜索

| ID | 需求 | 优先级 |
| --- | --- | --- |
| FR-19 | 按标题、作者、标签筛选文库。 | 高 |
| FR-20 | 跨论文正文、笔记、对话全文检索，显示命中片段，可按类型过滤并直达；≥2 字中文可命中正文；至少验收 脱靶/off-target、半衰期/half-life、野生型/wild-type 三组中英互搜；不支持时须明示。 | 高 |
| FR-21 | 会话自动命名并可编辑；支持按论文/时间筛选，避免大量 Untitled/「PDF 分析」。 | 中 |

### 设置与数据

| ID | 需求 | 优先级 |
| --- | --- | --- |
| FR-22 | 配置模型服务地址、模型名与 API key，并提供连接测试。 | 高 |
| FR-23 | API key 加密保存；界面、日志、导出包均不得出现明文；界面最多显示末四位。 | 高 |
| FR-24 | key 缺失或失效时禁用问答与翻译并说明原因。 | 高 |
| FR-25 | 显示请求与会话累计 token；费用估算需配置单价，未配置时只显示 token，不编造金额。 | 中 |
| FR-26 | 支持指定数据根目录、整库导出/导入（不含 key）；卸载默认保留数据，另设彻底删除；同一数据目录只允许一个实例写入，冲突时只读或提示。 | 中 |

### 修订新增

| ID | 需求 | 优先级 |
| --- | --- | --- |
| FR-27 | 重复导入同一 PDF（含文件名不同、内容相同）不得产生重复条目，以内容哈希判重；同一论文的不同版本不合并，可标注版本。 | 中 |
| FR-28 | 附件原文件被移动/删除时条目保留并提示；库目录整体移动/重命名后支持批量重定位。 | 高 |
| FR-29 | Zotero 迁移仅在源数据质量合格时提供；导入前预检，逐条报告 skipped 及原因。 | 低（v1.1） |
| FR-30 | AI 回答可一键保存为笔记，自动带论文与页码来源。 | 中 |
| FR-31 | 429 单独退避并提示；流式中断保留半截内容、标记「未完成」、可续写；不重放已成功的工具调用。 | 高 |
| FR-32 | 跨文献联合检索与汇总：在文库内按主题检索多篇论文的相关段落，结果标注篇名/页码。v1 不承诺，界面不得暗示可一次问多篇。 | 中（v1.1） |

## 3. 非功能性需求（修订版）

| ID | 类别 | 需求 | 验收方式 |
| --- | --- | --- | --- |

| NFR-02 | 性能 | 本系统附加延迟目标 ≤ 300 ms；模型请求超 10 秒须显示进度并可取消。 | 实测回填；不达标写明瓶颈 |

| NFR-08 | 安全性 | key 非明文保存；复制到另一账户后不可解。 | 跨账户实测 |
| NFR-09 | 隐私 | 外联目标白名单；代码审查 + 一次抓包抽查；连接测试属配置行为，单独说明。 | 抓包 + 代码审查 |
| NFR-10 | 隐私 | 发送前可查看内容范围；可关闭 AI；卸载默认保留数据，另设彻底删除。 | 走查 + 删除后磁盘扫描 |
| NFR-11 | 兼容性 | Windows 10 1809+ 与 Windows 11 x64 各一台实机跑通高优先级用例；125%–200% 缩放无重叠/截断；测试机型号写明。 | 实机记录 |
| NFR-12 | 兼容性 | 支持带文本层 PDF；加密、扫描件、损坏文件给出可读提示且不崩溃。 | 样本走查 |

| NFR-14 | 成本 | token 与费用可见；未配置单价只显示 token；同页译文重复查看不产生新费用。 | 账单对照 |
| NFR-15 | 合规 | 不内置论文内容；首次导入提示版权责任；AGPL 翻译工具不打包、不链接、不修改；默认不采集遥测。 | 依赖清单 + 安装包检查 |

| NFR-17 | 首次索引 | 首次建索引有进度与磁盘占用提示，不阻塞阅读；索引损坏可重建。 | 冷启动走查 + 重建 |

## 5. C 版特征（供对比用）

**优点**

- 角色分工带来了真正的分歧：用户 Agent 的「编页码、静默截断、中英检索、批注丢失」是访谈式没问出来的。
- 评审者按 8 条标准逐条挑错，抓到了「隐私被降级为假设」「页码由模型自报」「验收数字无来源」这类结构性问题。
- 假设、依赖、风险、开放问题都显式标注，便于后续决策。

**缺陷**

- 初版仍然是「功能清单」而非「可验收基线」：痛点被翻译成功能名词时丢了判据。
- 有过度设计：并排分隔条、逐段对齐、按页缓存、5 名用户可用性测试、2000 篇/1 秒等。
- 评审环节虽然有效，但评审者只能审文档；它不知道「500 页 PDF 首屏 2 秒」在真实机器上是否成立，也不知道 Zotero 导入为什么被撤掉。
- C 版的质量高度依赖评审者的提示词；如果只让它「看看有没有问题」，它会顺着文档逻辑走，挑不出「需求已经改写掉用户诉求」。
