思懿是一个为科研工作流打造的本地优先桌面应用：把**读论文、管文献、译文献、问 AI** 收在一个窗口里。所有数据保存在本机（SQLite + 磁盘文件），API 密钥经系统密钥加密，上传给模型的内容范围在界面上始终可见。

程序意外退出（断电、任务管理器结束进程）也不会丢掉已经生成的那半截回答 —— 重新打开时会告诉你上一轮断在哪儿，并给一个「继续写」。

它不是「套壳聊天框」。打开一篇论文之后，**模型是真的读到了正文** —— 可以按页读、可以在全文里检索，界面上那行「已读到《…》· N 页」就是它确实看见了的凭据。

## 功能一览

|     | 功能           | 说明                                                                                                                                                                                                 |
| --- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 💬  | **AI 对话**    | 接入任意 OpenAI 兼容服务商（DeepSeek、智谱、MiniMax、致远一号、自定义）；厂商与模型分两级选择；对话按首条消息自动命名；思考过程可展开；回答支持 LaTeX 与代码块                    |
| 📄  | **论文阅读**   | PDF.js 阅读器，虚拟滚动、缩放；左侧列出文库里的文献，**点一条就地打开**；阅读时右侧「AI 助读」可就这一篇提问                                                                    |
| 🤖  | **AI 真能读论文** | 模型拿到的是正文而不只是文件名：可读指定页码、可在全文检索关键词；问「这篇的创新点」时它会先去读，再回答                                                                     |
| 📚  | **文库**       | 照 Zotero 的组织方式：可任意嵌套的分类树、条目、标签、笔记、附件；一个条目可同时属于多个分类；**从资源管理器直接拖 PDF 进窗口**即可入库                                            |
| ✨  | **元数据补全** | 从 PDF 首页认出 DOI，去 CrossRef 把标题、作者、期刊、年份、卷期页一次补全（免费、无需 key）                                                                                     |
| 🌐  | **论文翻译**   | 把英文论文译成中文，在阅读器里**原文 / 双语对照**一键切换（**需自行安装一个配套程序，见下**）                                                                                |
| 🔍  | **全局搜索**   | `Ctrl K` 一次搜遍**对话内容、文库、日记**；命中处高亮，回车直达那一条。中文两个字就能搜到正文 —— 不要求你记得那句话是在标题里还是正文里 |

**本地优先与安全边界**：数据与索引保存在本机 SQLite；API 密钥经 Electron `safeStorage` 加密，**绝不进入渲染进程**，界面上只能看到末四位；渲染进程不接触文件系统、数据库与凭据，一切经受控 IPC 通信。删除 `%APPDATA%\siyi\` 即可完全清除本应用的数据。

## 论文翻译

**思懿自己不实现翻译。** 它调用的是你本机运行的 [zotero-pdf2zh](https://github.com/guaguastandup/zotero-pdf2zh) 服务 —— 一个把英文 PDF 译成中文并**重建排版**的工具（译文 PDF 的版面和原文一致，公式图表各就各位）。

### 为什么要你另外装

1. **许可证**。那个工具，以及它依赖的 pdf2zh / BabelDOC / PyMuPDF，**都是 AGPL-3.0**。思懿不能把它打包进安装包 —— 那等于分发它，会把整个项目拖成 AGPL。所以它必须由你**自己安装、自己运行**，思懿只通过本机 HTTP 调用。思懿**不打包、不链接、不修改**它的任何代码。
2. **体积**。它依赖一个 Python 运行时、PyMuPDF 的原生库和版面分析模型，塞进安装包会让体积从几十 MB 涨到三百 MB 以上。

**不装它也完全能用思懿** —— 只是「论文翻译」这个入口会提示你去哪儿装，其余四个模块不受影响。

### 怎么装

按 [zotero-pdf2zh 的官方文档](https://github.com/guaguastandup/zotero-pdf2zh) 走。Windows 上它提供整合包，大体流程：

1. 下载并解压整合包 —— **里面自带 Python 环境，不用另外装 Python**
2. 双击 `start.bat` 启动服务
3. 等窗口里出现 `Running on http://127.0.0.1:9010` 就成了 —— **这个窗口别关**，关了服务就停了
4. 回到思懿，打开一篇论文，表头会出现「翻译」

**依赖有哪些**（官方整合包都带了，列在这里是给想自己编译的人看的）：

| 依赖             | 说明                                                        |
| ---------------- | ----------------------------------------------------------- |
| Python 3.12      | 整合包自带                                                  |
| PyMuPDF          | PDF 解析与重排 · AGPL-3.0                                   |
| BabelDOC         | 版面分析与双语对照排版 · AGPL-3.0                           |
| pdf2zh / pdf2zh_next | 翻译管线 · AGPL-3.0                                     |
| **翻译后端**     | ⚠️ 见下                                                     |

> [!NOTE]
> **最后一项最容易被忽略**：它是条管线，翻译那一步要调大模型。它自带一个免费服务，但那是**限流的社区服务，不适合长期依赖**。认真用的话，建议在它的配置里填上你自己的 LLM API key（DeepSeek、智谱、任意 OpenAI 兼容端点都行）。

### 思懿怎么找到它

**默认什么都不用配。** 思懿会去 `127.0.0.1:9010`（那个工具的默认端口）探活，通了就在阅读器表头显示「翻译」按钮；没找到会在附近两个端口再试一次。

改过端口、或把服务跑在别处的话，去 **设置 → 论文翻译** 填地址 —— 填完会立刻告诉你通没通。

> [!NOTE]
> 思懿只做 HTTP 客户端：提交 PDF、订阅进度、取回译文。它在**设置 → 论文翻译**里能看到当前连的是哪个地址、服务是什么版本。
